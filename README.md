## 🛡️ Final Year Project: PhantomBox
**Resource-Efficient Malware Analysis Sandbox**

> A lightweight, evasive-resistant environment designed to capture modern malware behavior without the overhead of traditional sandboxes.

<div align="center">
<img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white"/> <img src="https://img.shields.io/badge/QEMU-FF6600?style=flat-square&logo=qemu&logoColor=white"/> <img src="https://img.shields.io/badge/Tiny10-0078D6?style=flat-square&logo=windows&logoColor=white"/>
</div>

- **Anti-Virtualization Detection**: Built-in mechanisms to bypass malware checks for VM environments, ensuring more reliable capture of evasive samples.
- **User-Activity Simulation**: Mimics human interaction (mouse movements, keystrokes, application usage) to defeat sandbox-evasion techniques.
- **Live Monitoring Dashboard**: Real-time observation and logging of malicious behavior in a strictly controlled environment.
