**Digital Forensics Analyzer**
Extracts Windows registry artifacts and organizes investigative findings into structured, reviewable output.
<img src="https://skillicons.dev/icons?i=py,flask,windows&theme=dark&perline=5" height="32"/>

**Secure Voting System**
Security-focused voting platform exploring authentication, authorization, database integrity, and async processing.
<img src="https://skillicons.dev/icons?i=flask,js,postgres,redis&theme=dark&perline=5" height="32"/>

**ZapNik Security Scanner**
Unified web-security scanning interface combining OWASP ZAP and Nikto for orchestrated server + application assessment.
<img src="https://skillicons.dev/icons?i=py,flask&theme=dark&perline=5" height="32"/>
